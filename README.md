# ReadyAPI (readyapi)
ReadyAPI is SmartBear's enterprise-grade automated API testing platform. It unifies functional, security, performance, and virtualization testing for REST, SOAP, GraphQL, Kafka, JDBC, and JMS APIs. ReadyAPI is delivered as a desktop and CI/CD tool rather than as a public REST API, integrating with Jenkins, Azure DevOps, Git, and other automation platforms via TestEngine.
